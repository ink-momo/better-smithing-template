# Better Smithing Template

中文 | [English](./README.md)

重写了锻造机制，给您更好的锻造体验。

## 这个模组是做什么的？

在原版 Minecraft 中，锻造台里用的锻造模板是一次性的——用一次就没了。这个模组让模板变得像工具一样，可以重复使用多次，用坏了才会消失。

## 主要特点

- **模板可多次使用**：为模板添加耐久系统，默认耐久为 3 ，用完消失。
- **自动识别模板**：理论可自动识别游戏内所有锻造模板，包括其他模组添加的模板，无需手动配置。
- **灵活配置**：如遇到无法自动识别的锻造模板，也可以通过手动添加列表来指定。

## 配置说明

配置文件位于游戏目录下的 `config/better_smithing_template.toml`，可以用记事本打开编辑。

| 选项 | 默认值 | 说明 |
|------|--------|------|
| `auto_detect_templates` | `true` | 自动识别游戏内所有锻造模板。关闭后需要手动在下方列表中指定 |
| `target_items` | 内置示例 | 需要手动添加耐久的模板列表，每行写一个，格式为 `模组名:物品名` |
| `max_damage` | `3` | 锻造模板可使用的次数。设为 `0` 则关闭耐久功能（恢复原版行为）。范围 0-5 |

## 兼容性

- 目前支持 Minecraft 1.21.1 + NeoForge
- 理论可兼容大部分添加新锻造模板的模组
- 不修改原版配方，不影响其他模组的正常功能

## 常见问题

**Q：模板放在背包里还能堆叠吗？**
A：可以。相同的模板可以在背包里堆叠。

**Q：可以把使用次数设得更高吗？**
A：可以。如果你需要更多次数，可以在配置中调整 `max_damage` 的值。

**Q：模组没能自动识别到的锻造模板，如何手动添加？**
A：首先你要确认模板的物品注册名，例如 `cataclysm:ignitium_upgrade_smithing_template` 。然后在配置文件中的 `target_items` 手动添加该模板。
